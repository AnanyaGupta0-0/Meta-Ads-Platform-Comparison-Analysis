# Meta-Ads-Platform-Comparison-Analysis

An interactive **Power BI dashboard** designed to compare advertising performance across Facebook and Instagram while providing platform-specific insights into campaign effectiveness, audience engagement, and conversion metrics.

## Project Overview

This project focuses on analyzing digital advertising performance across two major social media platforms: Facebook and Instagram. It provides a comparative view of campaign performance along with dedicated platform-wise dashboards to examine key advertising metrics and identify performance patterns.

The dashboard transforms advertising data into interactive visual insights, helping users understand campaign effectiveness and evaluate performance across platforms.

## Dashboard Features

- **Cross-Platform Comparison:** Compare Facebook and Instagram advertising performance through key metrics and visualizations.
- **Platform-wise Analysis:** Dedicated dashboards for detailed Facebook and Instagram performance analysis.
- **Campaign Performance:** Examine campaign-level metrics to understand advertising effectiveness.
- **Engagement Analysis:** Track impressions, clicks, click-through rate (CTR), and engagement rate.
- **Conversion Analysis:** Monitor conversion-related metrics, including purchases and conversion rate.
- **Interactive Filtering:** Explore data using available date, campaign, platform, and other dashboard filters.
- **Time-Based Insights:** Analyze advertising activity and performance trends across different time periods.

## Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Impressions | Total number of times advertisements were displayed |
| Clicks | Total interactions through advertisement clicks |
| CTR | Percentage of impressions that resulted in clicks |
| Engagement Rate | Measures audience interaction with advertisements |
| Conversion Rate | Measures the proportion of interactions resulting in conversions |
| Purchases | Total purchases attributed to advertising activity |
| Budget | Advertising budget allocated to campaigns |

## Tools & Technologies

- **Power BI** – Dashboard development and data visualization
- **DAX** – KPI calculations and analytical measures
- **Power Query** – Data preparation and transformation

## Dataset Structure

The Power BI data model includes the following tables:

- `ad_events`
- `campaigns`
- `ads`
- `users`
- `Calender Table`

These tables support the analysis of advertising events, campaign information, audience data, and time-based performance.

## Dashboard Pages

1. **Comparison Dashboard** – Provides a comparative overview of Facebook and Instagram advertising performance.
2. **Instagram Dashboard** – Presents detailed Instagram campaign and engagement insights.
3. **Facebook Dashboard** – Provides platform-specific Facebook advertising analysis.
4. **Calendar Tooltip** – Supports additional date-based context within the dashboard.

## Project Objectives

- Compare advertising performance across Facebook and Instagram.
- Understand campaign-level engagement and conversion patterns.
- Identify differences in platform performance using measurable KPIs.
- Present advertising data through interactive and easy-to-understand visualizations.

## How to View the Project

1. Clone or download this repository.
2. Download and install [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
3. Open the `.pbix` file in Power BI Desktop.
4. Interact with the dashboard pages, filters, and visualizations.
